# Feature

New or changed behaviour. **You own the shape.** The ticket is done when the behaviour works and the code is easier to change than before.

1. Read.
2. Shape. Say the call.
3. Refactor first, when the call says so.
4. Build the behaviour test-first.
5. Review with fresh eyes.
6. Fix.
7. Finish.

**Reply:** what was built, the call and what you refactored for it, the tests that went red then green.
