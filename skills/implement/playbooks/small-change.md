# Small change

A text, a value, or one line, and no shape signal. **Small, not careless.** The ticket is done when the change is in, tested, and nothing around it got worse.

1. Read.
2. Say the call: "Fits as it is: <why>." A shape signal fires: this is a feature, switch playbooks.
3. Build test-first: a test that pins the new text or value goes red, then green.
4. Review with fresh eyes, with one reviewer: the design reviewer, also asked for the Standards and Spec questions of `code-review`.
5. Fix.
6. Finish.

**Reply:** what changed, the test that pins it.
