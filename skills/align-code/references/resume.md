# Resume

Every session must stop safely and start cold from the files.

## Start

1. Read the header, the map, `gaps.md`, and the last five `log.md` lines. Not `survey/` or `research/` yet.
2. Turn every newly finished survey into gaps.
3. Print the board from [help.md](help.md).
4. Waiting gap past due: ask once: chase, extend, or accept the risk.
5. Start subagents for open survey and research gaps.
6. Choose one gap.

## Waiting on someone else

1. Status `waiting-on-input`. Who, when asked, when due go in the answer cell.
2. Give the person one question to paste: area, question, recommended answer, the form of answer needed. Never send it yourself.
3. Go on. It blocks only the gaps that list it.

The answer comes back: write it on the row with who and when. Close as usual.

## End

1. The row or ticket has its new status, and its answer or commit.
2. `log.md` has one new line.
3. `Updated` is today.
4. Say three lines: what changed, what waits on whom, what is next, by its question or title.

Outside apply: no commit, no branch switch, no push. The person commits the align folder.

## More than one run

One folder per run. Never mix them. Refuse `new` when its scope overlaps a run not `aligned` or `abandoned`, and name that run.
